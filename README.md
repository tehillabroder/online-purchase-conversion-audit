# Online Purchase Intention Prediction

This project explores whether online shopping sessions can be classified as purchase or non-purchase sessions using supervised machine learning.

The workflow includes data inspection, preprocessing, feature preparation, model training, model comparison and classification evaluation.

## Data source

This project uses the Online Shoppers Purchasing Intention Dataset from the UCI Machine Learning Repository.

Citation: C. Sakar and Y. Kastro, "Online Shoppers Purchasing Intention Dataset," UCI Machine Learning Repository, 2018. DOI: 10.24432/C5F88Q.
